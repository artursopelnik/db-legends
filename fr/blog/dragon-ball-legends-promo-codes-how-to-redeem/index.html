Codes promo Dragon Ball Legends : comment les trouver et les échanger

Mis à jour 12 juillet 2026 · Blog DBL QR

Bandai Namco publie de temps en temps des codes promo (codes cadeaux) pour Dragon Ball Legends – Chrono Crystals gratuits, tickets ou objets, généralement autour des anniversaires, collaborations et grandes annonces. Voici comment fonctionne l’échange, où trouver les codes qui sont réellement encore valides et comment éviter les sites d’arnaque.

Comment échanger un code promo

  1. Ouvrez Dragon Ball Legends et touchez Menu.
  2. Cherchez l’entrée code cadeau / code promo (dans la liste du menu ou sous Autre, selon la version).
  3. Saisissez ou collez le code exactement comme il a été publié – les codes sont généralement sensibles à la casse.
  4. Confirmez, puis récupérez la récompense dans votre boîte de cadeaux dans le jeu.

Si le jeu dit que le code est invalide, il a très probablement expiré – les codes promo ne sont souvent actifs que quelques jours ou semaines.

Où trouver des codes qui marchent encore

Les codes officiels proviennent d’un petit nombre de sources :

  • Les comptes officiels Dragon Ball Legends (X/Twitter, etc.) et les news dans le jeu.
  • Les livestreams et événements autour des anniversaires et du Legends Festival.
  • Les promotions de collaboration occasionnelles.

Le générateur de QR DBL a un panneau de codes promo intégré qui liste les codes actuellement connus avec leur date d’expiration et un lien vers la source – touchez un code pour le copier, puis collez-le dans le jeu. La liste est mise à jour régulièrement, vous évitez donc le cimetière de codes expirés que beaucoup de sites de « listes de codes » ne nettoient jamais.

Évitez les arnaques

Les résultats de recherche pour « Chrono Crystals gratuits » sont pleins d’arnaques de générateurs. Deux règles vous protègent :

  • Aucun site ne peut générer de Chrono Crystals. Toute page qui vous demande de remplir des sondages, de vous connecter avec votre compte ou de « vérifier » pour recevoir des cristaux est une arnaque.
  • N’entrez jamais vos identifiants de compte ailleurs que dans le jeu. Échanger un code promo ne demande jamais votre mot de passe ni votre code de transfert.

Les codes promo légitimes se saisissent uniquement dans le jeu lui-même – rien de plus.

Codes promo vs friend codes

Ne les confondez pas : les codes promo viennent de Bandai Namco et donnent des récompenses à tout le monde ; les friend codes identifient des joueurs individuels et servent à ajouter des amis ou à se scanner mutuellement pendant les événements Dragon Ball. Si c’est 8–10 caractères et que ça vient d’un autre joueur, c’est un friend code – voir notre guide friend codes et comment scanner les QR codes d’amis.
