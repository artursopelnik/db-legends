QR code Dragon Ball Legends qui ne scanne pas ? 7 solutions qui marchent

Mis à jour 16 juillet 2026 · Blog DBL QR

Vous pointez le scanner du jeu sur un QR code et… rien ne se passe. Les problèmes de scan dans Dragon Ball Legends se ramènent presque toujours à une poignée de causes – voici les solutions, dans l’ordre où elles résolvent le problème le plus souvent.

1. Régénérez le QR code (solution la plus fréquente)

Dragon Ball Legends n’accepte que les QR codes avec un timestamp frais. Un QR généré il y a quelques heures – ou une capture d’écran envoyée hier – sera simplement ignoré par le scanner. Ouvrez le générateur de QR, touchez Régénérer et scannez immédiatement. Ça résout la majorité des cas de « scanner qui ne fait rien ».

2. Vérifiez qu’un événement de scan est bien en cours

L’option Scanner le QR code dans Menu → Amis n’est active que pendant les campagnes de scan (typiquement les périodes anniversaire et Legends Festival). En dehors de ces fenêtres, le scanner n’est même pas disponible – aucun QR code ne marchera, même parfaitement frais.

3. Vérifiez le friend code lui-même

Un QR généré à partir d’un friend code mal tapé se scanne très bien, mais pointe vers le mauvais joueur (ou aucun). Les friend codes font 8–10 lettres et chiffres – attention aux confusions classiques comme 0 vs o et 1 vs l. Demandez à votre ami de copier le code directement depuis son jeu (Menu → Amis) plutôt que de le taper de mémoire.

4. Corrigez l’écran, pas le code

  • Luminosité au max sur l’appareil qui affiche le QR.
  • Évitez les reflets – inclinez l’écran à l’écart des lampes et fenêtres.
  • Agrandissez-le – touchez le QR code dans le générateur pour l’afficher en plein écran.
  • Désactivez le mode nuit / filtres de lumière bleue, qui réduisent le contraste.

5. Vous avez déjà scanné ce joueur

Chaque ami unique ne peut vous donner qu’une seule Dragon Ball par période d’événement. Si le scanner lit le code mais que rien n’est attribué, vous avez probablement déjà scanné ce joueur – il vous faut des codes d’amis différents. Les threads communautaires de friend codes sont une bonne source ; voir comment trouver et partager des friend codes.

6. Problèmes de caméra et d’autorisations

Si l’écran du scanner reste noir, il se peut que le jeu n’ait pas la permission caméra. Vérifiez les paramètres des apps de votre téléphone, accordez l’accès caméra à Dragon Ball Legends et relancez le jeu. Nettoyer l’objectif de la caméra aide plus souvent qu’on ne le pense.

7. Redémarrez le jeu

Le classique. Si l’événement est bien en cours, le code frais et la caméra fonctionnelle mais le scan échoue toujours, fermez complètement Dragon Ball Legends et rouvrez-le. Des hoquets serveur pendant les journées chargées d’anniversaire peuvent aussi causer des échecs temporaires – attendre quelques minutes et réessayer suffit parfois.
