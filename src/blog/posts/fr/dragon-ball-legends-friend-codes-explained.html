Votre friend code est votre identifiant de joueur dans Dragon Ball Legends – une courte chaîne de 8–10 lettres et chiffres que d’autres joueurs utilisent pour vous ajouter en ami ou vous scanner pendant les événements de collecte des Dragon Balls. Voici où le trouver, comment le partager et comment utiliser réellement les codes que vos amis vous envoient.

Où trouver votre friend code

  1. Ouvrez Dragon Ball Legends.
  2. Touchez Menu → Amis.
  3. Votre friend code s’affiche en haut de l’écran.

Dites à vos amis de regarder au même endroit – chaque joueur en a un, et il ne change pas.

Comment partager votre friend code

Copiez le code et envoyez-le comme vous voulez : WhatsApp, Discord, Reddit ou un groupe avec votre équipe. Comme c’est du texte simple, c’est bien plus facile à faire circuler qu’une capture d’écran de votre QR code du jeu – et contrairement à une capture, il n’expire jamais, puisque celui qui le reçoit peut générer un QR frais à partir de lui à tout moment.

Si vous rassemblez plusieurs codes d’une communauté (par exemple un thread de friend codes sur Reddit ou Discord pendant un événement d’anniversaire), vous pouvez tous les garder dans une liste dans le générateur de QR DBL – il stocke les codes localement dans votre navigateur et peut même partager toute votre liste sous forme de lien en une touche.

Du friend code à la Dragon Ball

Pendant les événements de scan, les friend codes sont la matière première pour collecter des Dragon Balls :

  1. Collectez les friend codes d’autres joueurs.
  2. Collez-les dans le générateur de QR – chaque code devient une image QR scannable.
  3. Dans le jeu, ouvrez Menu → Amis → Scanner le QR code et scannez chaque QR depuis un second écran.
  4. Chaque joueur unique que vous scannez vous donne une Dragon Ball.

Le pas à pas complet avec astuces est dans notre guide comment scanner les QR codes d’amis.

Est-il sûr de partager votre friend code ?

Oui. Un friend code permet seulement à d’autres joueurs de vous envoyer une demande d’ami ou de vous scanner pendant les événements – il ne contient aucun identifiant de compte et ne peut pas être utilisé pour accéder à votre compte. Ne partagez jamais votre code de transfert de compte ni votre mot de passe, en revanche : ce sont des choses complètement différentes et elles doivent rester privées.

Questions fréquentes

Quelle est la longueur d’un friend code ?

8 à 10 caractères, uniquement des lettres et des chiffres.

Puis-je changer mon friend code ?

Non – il est lié à votre compte et reste le même.

Les friend codes expirent-ils ?

Non. Seuls les QR codes générés à partir d’eux expirent, parce que le jeu veut un timestamp frais. C’est pour ça que vous régénérez le QR juste avant de scanner.
