Seu friend code é seu ID de jogador em Dragon Ball Legends – uma sequência curta de 8–10 letras e números que outros jogadores usam para adicionar você como amigo ou escanear você durante os eventos de coleta de Dragon Balls. Aqui está onde encontrá-lo, como compartilhá-lo e como usar de verdade os códigos que seus amigos enviam.

Onde encontrar seu friend code

  1. Abra o Dragon Ball Legends.
  2. Toque em Menu → Amigos.
  3. Seu friend code aparece no topo da tela.

Peça para seus amigos olharem no mesmo lugar – todo jogador tem um e ele não muda.

Como compartilhar seu friend code

Copie o código e envie do jeito que quiser: WhatsApp, Discord, Reddit ou um grupo com sua turma. Como é texto puro, é muito mais fácil de passar adiante do que uma captura de tela do seu QR code do jogo – e, ao contrário de uma captura, ele nunca expira, porque quem receber pode gerar um QR fresco a partir dele a qualquer momento.

Se você juntar vários códigos de uma comunidade (por exemplo, uma thread de friend codes no Reddit ou Discord durante um evento de aniversário), pode manter todos em uma lista no gerador de QR do DBL – ele armazena os códigos localmente no navegador e ainda consegue compartilhar a lista inteira como link com um toque.

Do friend code à Dragon Ball

Durante os eventos de scan, friend codes são a matéria-prima para coletar Dragon Balls:

  1. Colete friend codes de outros jogadores.
  2. Cole no gerador de QR – cada código vira uma imagem QR escaneável.
  3. No jogo, abra Menu → Amigos → Escanear código QR e escaneie cada QR de uma segunda tela.
  4. Cada jogador único que você escaneia dá uma Dragon Ball.

O passo a passo completo com dicas está no nosso guia como escanear QR codes de amigos.

É seguro compartilhar seu friend code?

Sim. Um friend code só permite que outros jogadores enviem uma solicitação de amizade ou escaneiem você durante eventos – não contém credenciais de conta e não pode ser usado para acessar sua conta. Nunca compartilhe seu código de transferência de conta nem sua senha, no entanto: são coisas totalmente diferentes e devem ficar privadas.

Perguntas frequentes

Qual o tamanho de um friend code?

8 a 10 caracteres, apenas letras e números.

Posso mudar meu friend code?

Não – ele está ligado à sua conta e permanece o mesmo.

Friend codes expiram?

Não. Só os QR codes gerados a partir deles expiram, porque o jogo quer um timestamp fresco. É por isso que você regenera o QR bem antes de escanear.
