Ваш friend code — это идентификатор игрока в Dragon Ball Legends: короткая строка из 8–10 букв и цифр, по которой другие игроки добавляют вас в друзья или сканируют во время событий сбора Dragon Balls. Вот где его найти, как им поделиться и как использовать коды, которые присылают друзья.

Где найти свой friend code

  1. Откройте Dragon Ball Legends.
  2. Нажмите Меню → Друзья.
  3. Ваш friend code показан в верхней части экрана.

Скажите друзьям смотреть в том же месте — у каждого игрока есть свой код, и он не меняется.

Как поделиться friend code

Скопируйте код и отправьте любым способом: WhatsApp, Discord, Reddit или чат с командой. Поскольку это простой текст, его гораздо проще пересылать, чем скриншот QR-кода из игры — и в отличие от скриншота, он никогда не истекает, ведь получатель может сгенерировать свежий QR из него в любой момент.

Если вы собираете несколько кодов от сообщества (например, из ветки friend codes на Reddit или Discord во время юбилейного события), храните их в одном списке в генераторе QR DBL — он сохраняет коды локально в браузере и даже умеет делиться всем списком по ссылке одним касанием.

От friend code до Dragon Ball

Во время событий сканирования friend code — сырьё для сбора Dragon Balls:

  1. Соберите friend code других игроков.
  2. Вставьте их в генератор QR — каждый код станет сканируемым QR-изображением.
  3. В игре откройте Меню → Друзья → Сканировать QR-код и отсканируйте каждый QR со второго экрана.
  4. Каждый уникальный игрок, которого вы отсканируете, даёт один Dragon Ball.

Полное пошаговое руководство с подсказками — в как сканировать QR-коды друзей.

Безопасно ли делиться friend code?

Да. Friend code позволяет другим игрокам лишь отправить вам заявку в друзья или отсканировать во время событий — он не содержит учётных данных и не может использоваться для доступа к аккаунту. При этом никогда не делитесь transfer code или паролем аккаунта: это совсем другое и должно оставаться приватным.

Частые вопросы

Какой длины friend code?

8–10 символов, только буквы и цифры.

Можно ли изменить свой friend code?

Нет — он привязан к аккаунту и остаётся тем же.

Истекают ли friend code?

Нет. Истекают только QR-коды, созданные из них, потому что игра требует свежую метку времени. Поэтому вы регенерируете QR прямо перед сканированием.
